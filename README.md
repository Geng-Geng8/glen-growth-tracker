# Glen Growth Tracker

Mobile-first personal business development tracker for Glen Reyes.

## Stage 1 — Today Screen

The current version focuses on daily sales behavior and fast one-tap tracking.

### Full Sales Mode
- 3 qualified contacts per day
- 3 follow-ups per day
- 1 revenue-moving action per day

### Travel Mode
Automatically active from September 9, 2026 through October 3, 2026:
- 1 qualified contact per day
- 1 follow-up per day

### Tracked actions
- Qualified Contact
- Follow-up
- Ask for Referral
- Software Interview
- Decision-Maker Conversation
- Next Step Scheduled
- Proposal / Quote Sent
- Booked Deal

### Current Stage 1 behavior
- In-memory session tracking only
- XP scoring
- Daily mission score
- Progress bars and completion states
- Automatic Travel Mode / Full Sales Mode switching
- Mobile-first responsive interface

Google Sheets persistence, offline storage, Week, Money, Wins, and PWA support are intentionally deferred to later stages.
